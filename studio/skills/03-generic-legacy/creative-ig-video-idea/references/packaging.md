# Packaging engineering — the surface that sells

A concept is sold by its surface before a word is spoken. Read this when a concept
feels true but flat, generic, or "fine but not grabby." Packaging is four surfaces:
cover text, title/spoken hook, the number, the first frame — plus the caption as a
bonus hook.

## 1. Cover text (the in-grid second hook)

The cover is the single highest-leverage surface — it's what competes in the feed
grid. Rules:

- **2–5 words. Bold. One key word dominant** (often ALL-CAPS). Anything longer doesn't
  read at thumbnail size.
- **It's a hook, not a label.** "My morning routine" is a label. "I DON'T WAKE UP TILL
  NOON" is a hook. The cover should create a question or a stake, not summarize.
- **Lead with the most loaded element:** the number, the tension, the taboo, or the
  outcome. "57g PROTEIN." "WOMEN ARE LOOKING." "$7,380 LAST MONTH."
- **Don't echo the spoken hook verbatim** — the cover and the spoken line should be two
  *different* hooks that compound, not a copy. (One sells the click; the other sells
  the stay.)
- **Pair with the first frame** so text + image together make one stopping image.

Quick test: cover the rest of the video and show only the cover frame to a stranger.
If they don't feel a pull to know more, the cover is a label. Rewrite it.

## 2. Title / spoken hook (first 2 seconds)

Patterns that work, roughly strongest-first for a small account:
- **Number-led:** "I saved 11 hours last week doing this." Concrete beats adjectives.
- **Curiosity gap:** "the part of [X] nobody tells you." Open the loop, withhold the close.
- **Contrarian:** "you're using [X] wrong." Negate a default belief.
- **Outcome/result:** "this built me [specific result]." Lead with the receipt.
- **Question the viewer is already asking:** "is [X] actually worth it?"
- **Confession:** "I was too embarrassed to admit this." Vulnerability for a small account.
- **POV stack (strong for on-screen title):** `POV: [specific context] + [stereotype it kills] + [exact payoff number]`. Each slot does a job — context targets the audience, the killed stereotype is the conflict, the number is the proof. Example: "POV: kuliah di China, ga ketemu Wuling/BYD — Rp12 M buat 8 mobil." Tighter and hookier than any single-clause title because it lands the audience, the tension, and the payoff at once.

**Brand-censoring trick:** lightly mask brand names in titles/captions ("W\*ling," "the one that rhymes with…") on platforms that suppress or down-rank brand mentions. It dodges the filter *and* reads as cheeky/insider, which adds curiosity.

Avoid: throat-clearing ("hey guys so today"), summarizing instead of hooking, and
adjectives doing the work a number should do.

## 3. The number (the credibility anchor)

A specific number is the cheapest, strongest upgrade to almost any concept. It makes
a claim concrete, screenshot-able, and arguable.

- **Find the number in any topic.** Time saved, money made/spent, count of things,
  a grade, a percentage, days elapsed, a macro, a price, a total. There's almost always one.
- **Exact beats round — to the unit.** "Rp 798,773,278" outperforms "around 800 million";
  "$7,380" beats "~$7k"; "47 emails" beats "a lot." The unrounded figure reads as real,
  not estimated, and is the thing people screenshot. Put the precise number on the card.
- **Surprising beats big.** A number that violates expectation (high or low) hooks more
  than a merely large one. "My worst grade was my most valuable class — 76."
- **Real, always.** If you can't verify the creator has the number, flag it and convert
  to a process frame. A fake number is a flop waiting for the body to expose it.

### Escalation: the running total

For any reveal/listicle video (rating things, opening prices, counting items), run a
**visible total that climbs** as you go — a ticker in the corner that adds up with each
item. It manufactures an open loop ("how high does it get?"), rewards watching to the
end with a payoff number, and makes the final figure shareable. Order items to **climb
to a peak** (cheap → jaw-dropper), and put the twist just before the finale, not at it.
The total reveal at the end is its own beat with a big card.

## 4. First frame / thumbnail visual

What the eye lands on in the half-second before the cover text registers:
- **Face mid-emotion** — surprise, intensity, a real laugh. Eyes to camera. Humans stop
  for faces.
- **The finished result** — open on the artifact/outcome (result-first is more credible
  than promise-first).
- **The before-state** — for transformations, the start is the hook.
- **A prop / visual signature** — a recurring object (timer, glasses, a whiteboard) that
  becomes part of the brand and aids recall across a series.
- **Motion or a "wrong" detail** — something slightly off that the eye wants to resolve.

## 5. Caption / first comment (the third hook)

The caption is a second open loop, not a description. Use it to deepen curiosity ("the
3rd one broke my brain"), pose the comment-bait question, or extend the story. Don't
waste it restating the video. A pinned first comment can plant the debate.

## Putting it together — the package, in order

1. Pick the **format** (formats.md) → it sets the skeleton.
2. Find the **number** → the credibility anchor.
3. Write the **cover text** → the in-grid hook (2–5 words, a hook not a label).
4. Choose the **first frame** → what we freeze on.
5. Write the **spoken hook** → a *different* hook than the cover.
6. Add the **caption** → the third loop.
7. Run the 5-axis idea score → fix the weakest surface.

If any of cover / number / first frame is missing, the concept isn't packaged yet —
it's still a topic.
