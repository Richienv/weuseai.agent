# Platform Length Rules

> Reference yang dipakai `post-drafter`. Length budget + structure per platform.

---

## TikTok caption
- **Sweet spot:** 100-140 char (preview shows ~80 char before truncate)
- **Cutoff:** 150 char (then "more" link)
- **Structure:** Hook + 1-2 body line + CTA + hashtags (4-8 tags)
- **Hashtag block:** at end, separated by spaces

## Reels caption
- **Sweet spot:** 80-120 char
- **Cutoff:** 125 char before truncate
- **Structure:** Hook + body + CTA + hashtags (5-10 tags)
- **Hashtag block:** at end

## X post (single)
- **Cutoff:** 280 char hard limit (Premium 4000)
- **Structure:** Hook → 1 punchy body sentence → optional CTA. Often single-thought.
- **Hashtag policy:** 0-2 tags max (X culture penalizes tag-stuffing)

## X thread
- **Per tweet:** 250-280 char
- **Structure:** Tweet 1 = hook + "🧵 thread" or "1/N" indicator. Tweets 2-N = one idea each. Final tweet = CTA + thread navigation tip.
- **Length:** 5-15 tweets typical

## LinkedIn post
- **Sweet spot:** 600-1300 char (algorithm favors substantial posts)
- **Cutoff:** ~1500 before "see more"
- **Structure:**
  - Line 1: Hook (drives "see more" click)
  - Lines 2-3: Hook expansion
  - Body: 3-5 short paragraphs (1-2 sentences each)
  - Closer: Reflection or CTA
  - Hashtags: 3-5 at end (LinkedIn likes fewer tags than IG/TikTok)

## Blog post
- **Sweet spot:** 800-2000+ words (SEO + reader satisfaction)
- **Structure:**
  - H1: SEO-keyword title (50-60 char)
  - Intro paragraph: hook + summary of value
  - H2 sections (3-7 typical)
  - Closer: CTA or next-action
  - Meta description: 140-155 char
- **Internal:** code blocks, lists, images break up text

## Threads (Meta) post
- **Sweet spot:** 250-500 char
- **Cutoff:** 500 char hard limit
- **Structure:** More conversational than X. Story-arc OK. Personal-voice land well.
- **Hashtag policy:** 1-3 tags

## Facebook post
- **Sweet spot:** 200-500 char (longer reduces reach)
- **Structure:** Personal-style intro + body + CTA
- **Hashtag policy:** 1-3 tags (FB is light on tags)

## Instagram caption (post + Reels)
**Note:** Reels caption follows Reels rules above. Post (carousel / single image):
- **Sweet spot:** 125-300 char (preview shows ~125 before "more")
- **Cutoff:** 2200 char hard limit
- **Structure:** Hook + body + CTA + hashtags (5-15)

## Universal voice rules (per CLAUDE.md)

Apply across all platforms:
- BI primary, English for technical terms
- `kamu` form (banned: `Anda`, `lo`, `gue`)
- Zero exclamation marks in body, max 1 per caption
- Banned words: `basically`, `just`, `literally`, `honestly`, `kind of`, `pretty much`, `revolutionary`, `disrupt`, `10x`, `game-changer`, `next-level`
- Calm-premium register default (override per voice profile)
- Max 1-2 emoji per post (override per voice profile)

---

## Length-fit validation (skill-side)

Post-drafter rejects draft if:
- Exceeds platform hard cutoff
- Below platform minimum (mis. LinkedIn <300 char = under-utilizes)
- Hashtag count outside platform-typical range

Soft warnings:
- Hook line >150 char (might lose reader before "more" click)
- Paragraph >5 sentences (LinkedIn / blog only — wall-of-text risk)
- All-caps words (looks shouty unless intentional acronym)
