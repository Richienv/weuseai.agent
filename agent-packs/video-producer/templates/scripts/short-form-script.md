# Template — Short-form script (TikTok / Reels / Shorts)

Skrip 15-90 detik untuk vertical short-form. Hook 3 detik dulu — kalau hook gagal, sisanya nggak akan ditonton. Per-beat selalu pasang visual cue + audio cue biar editor langsung bisa eksekusi tanpa nebak.

---

## Variables

- `{niche}` — topic / vertical (fintok, kuliner, fashion, edukasi, dst.)
- `{duration_sec}` — 15, 30, 60, atau 90
- `{platform}` — TikTok / Reels / Shorts
- `{voice_register}` — calm-premium, playful-conversational, educational, premium-niche
- `{cta_intent}` — save, comment, share, follow, link
- `{customer_name}` — pelanggan yang ngumpulin script (untuk handoff note)

---

## Template

```
SHORT-FORM SCRIPT — {duration_sec}s {platform}
Niche: {niche}
Voice: {voice_register}

Bet tag: [high hook potential | experimental | safe ship]

────────────────────────────────────────

────────────────────────────────────────

────────────────────────────────────────

────────────────────────────────────────

Visual cue:       <cut type + subject + B-roll suggestion>

────────────────────────────────────────
BEAT 3 — PAYOFF (0:0X – 0:YY)
────────────────────────────────────────

────────────────────────────────────────

────────────────────────────────────────

────────────────────────────────────────

────────────────────────────────────────

- Shoot order: <urutan shoot, paling efisien lokasi/talent>
- Props: <list>

```

---

## Tone guide

- Hook line **muscular**: kata kerja aktif, present tense, zero filler. Bukan "Hari ini aku mau cerita tentang…", tapi "Saldo nge-cry tanggal 25?"
- Setup tetap padat. Satu kalimat, satu ide. Kalau setup butuh dua kalimat, beat-nya terlalu lebar.
- Payoff harus jadi **kalimat yang orang mau screenshot**. Kalau payoff masih bisa di-paraphrase tanpa kehilangan inti, belum cukup tajam.
- CTA spesifik. "Save buat reminder pas gajian" mengalahkan "save video ini" tiap saat.
- Banned: `basically`, `just`, `literally`, `honestly`, `kind of`, `pretty much`, `revolutionary`, `disrupt`, `10x`, `game-changer`, `next-level`.
- Zero exclamation mark. Period titik selalu cukup.
- Kalau kamu lihat skrip lebih sibuk dari ceritanya, potong dua beat. Cerita dulu, shot belakangan.
