FAQ

Pertanyaan yang sering muncul.

Jawaban jujur, sebelum kamu mulai.

Saya gak tech-savvy, bisa pakai?+
Bisa. Setup otomatis — nggak install apa pun, nggak perlu tau coding atau VPS. Cukup chat di Telegram seperti chat sama temen. Agent yang ngerjain.
Bahasa apa yang didukung? Bisa pure Bahasa Indonesia?+
Default Bahasa Indonesia. English juga didukung penuh. Chat campuran (Bahasa + English) jalan natural.
Aman buat data bisnis saya?+
Agent jalan di server VPS pribadi kamu, bukan dibagi dengan customer lain. Memori chat nggak dibagi ke kami, bukan data training. Template yang kamu bangun tetap di server kamu.
Bisa pakai metode pembayaran apa?+
Bank transfer (semua bank Indonesia), GoPay, OVO, DANA, ShopeePay, kartu kredit/debit. Lewat Xendit (gateway pembayaran Indonesia).
Apa beda dengan subscription biasa?+
Setup-nya beneran sekali bayar — kamu beli kerja engineering yang sudah kami lakukan. Hosting Rp 99rb/bulan transparan: itu biaya server yang real, kayak bayar listrik. Berhenti kapan saja — tagihan berhenti, setup tetap kamu punya.
Kenapa harus bayar hosting kalau setup sudah dibayar?+
Setup itu kerja kami sekali (konfigurasi VPS, install agent, tune ke gaya kamu). Hosting itu biaya VPS yang jalan untuk kamu — server butuh listrik dan resource yang real. Kami nggak mau pura-pura itu gratis; lebih jujur kalau transparan.
Kalau nggak cocok atau mau berhenti?+
Berhenti kapan saja — tagihan hosting berhenti, setup tetap milik kamu. Kebijakan refund tertulis, link-nya di footer. Mau lanjut lagi nanti, tinggal bilang.
Berapa lama proses setup sampai agent saya jalan?+
Sekitar 8 menit setelah bayar — angka yang kami ukur, bukan janji. Agent makin nyambung setelah beberapa hari dipakai, karena dia ingat percakapan dan menyesuaikan gaya kamu.
Berapa biaya LLM-nya?+
Kredit perkenalan sudah termasuk di setup — cukup untuk ratusan pesan pertama. Setelah itu kamu pakai kunci API sendiri (DeepSeek mulai dari puluhan ribu rupiah per bulan untuk pemakaian normal). Kami bantu pasang, dan biayanya transparan langsung ke penyedia, tanpa markup dari kami.
Apa beda dengan ChatGPT atau Claude biasa?+
ChatGPT nunggu kamu tanya. Agent ini ngerjain duluan: briefing pagi, ringkasan sore, draf dokumen dan caption dari template Indonesia, riset web, dan playbook multi-langkah — sambil ingat percakapan kamu lintas hari. ChatGPT bantu kamu mikir; agent ini bantu kamu kerja.
Kalau saya cancel di tengah jalan, uang setup balik?+
Setup nggak bisa di-refund karena itu kerja engineering yang sudah kami selesaikan untuk kamu. Tapi 14 hari pertama setelah onboarding — kalau ada masalah teknis dari sisi kami yang bikin agent nggak bisa dipakai, kami tanggung: fix gratis atau refund penuh setup. Hosting bulanan tinggal stop kapan saja, tanpa komitmen.
Data dan percakapan saya disimpan di mana? Aman dari kebocoran?+
Server kamu ada di Singapore — paling dekat dan stabil untuk Indonesia. Data percakapan disimpan lokal di server kamu sendiri, bukan di server bersama. Kunci API dienkripsi at-rest. Kami nggak mengakses isi percakapan kamu kecuali kamu minta bantuan dan kasih izin eksplisit.
Always-On vs hosting biasa — kapan saya butuh Always-On?+
Untuk pemakaian harian — chat, briefing pagi, draf dokumen — hosting default sudah cukup. Always-On menjamin server kamu menyala 24/7 nonstop dengan prioritas penuh, untuk kamu yang menjadikan agent bagian kritis dari operasional harian.
Bisa lihat demo atau ngobrol dulu sebelum bayar?+
Bisa. Booking 15 menit lewat tombol "Konsultasi gratis" — kami tunjukkan agent live, jawab pertanyaan teknis, dan kamu bisa lihat workflow yang sebenarnya. Tanpa hard sell. Kalau nggak cocok, kami nggak follow up.
Kalau ada masalah teknis, gimana cara dapat support?+
Support lewat Telegram langsung ke tim kami. Tiap pelanggan dapat channel khusus — bukan chatbot, bukan antrian tiket yang panjang.
Kok resepnya dari China?+
Tim agent ini dipelajari di Zhejiang University, Hangzhou, lalu dirakit untuk Indonesia — template pajak, BPJS, KBLI, dan gaya bahasa lokal.
