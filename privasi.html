Kebijakan Privasi

Berlaku 9 Mei 2026

Kami menghargai privasi kamu. Halaman ini ngerangkum data apa yang kami kumpulin, gimana disimpan, kapan dihapus, dan hak kamu sebagai pelanggan.

1. Data yang kami kumpulin

  • Data akun: nama, email, nomor WhatsApp (buat support + invoice).
  • Data pembayaran: kami pakai Xendit untuk QRIS / e-wallet — kami sendiri gak nyimpen detail kartu atau saldo wallet kamu, hanya konfirmasi sukses/gagal.
  • Data agent: kredensial yang kamu kasih ke agent (Telegram bot token, LLM API key) disimpen di VPS kamu sendiri, ter-enkripsi di file .env. Kami gak akses tanpa permintaan eksplisit dari kamu.
  • Log teknis: uptime, error pipeline, performance metric — buat troubleshooting + improvement. Anonim, gak ngandung isi pesan kamu.

2. Yang gak kami kumpulin

  • Isi percakapan kamu sama agent — itu antara kamu, agent kamu, dan LLM provider kamu.
  • File yang kamu upload ke agent — disimpen di storage VPS kamu, bukan di server kami.
  • Behavioral tracking lintas situs — gak ada Facebook Pixel, gak ada Google Analytics yang tracking lintas page (kalau kami pasang analytics, hanya self-hosted Plausible / Umami yang anonim).

3. Penyimpanan + retensi

  • Data akun + payment record disimpan di Supabase (region Singapura) selama akun aktif + 12 bulan setelah cancel (buat compliance audit).
  • VPS agent kamu hidup di IDCloudHost (region Jakarta). Data agent dihapus 30 hari setelah kamu cancel hosting.
  • Backup harian VPS dihapus 7 hari setelah pembuatannya (rolling window).

4. Berbagi data

Kami gak jual data kamu ke pihak ketiga. Data hanya dibagi sama:

  • Xendit — buat process payment.
  • IDCloudHost — buat host VPS agent kamu.
  • Supabase — buat simpen account + transaction record.
  • Pemerintah Indonesia — kalau diminta sesuai hukum yang berlaku (PERDIRJEN, putusan pengadilan).

5. Hak kamu

  • Akses: minta export semua data kamu via email — kami kirim dalam 7 hari kerja.
  • Koreksi: ubah data akun kapan aja dari dashboard. Untuk record pembayaran, kirim email.
  • Penghapusan: minta hapus akun + semua data terkait. Kami proses dalam 14 hari (kecuali yang wajib disimpan secara hukum, e.g. invoice 5 tahun per UU PPN).

6. Cookies

Landing page ini gak pakai cookies tracking. Dashboard pakai cookies functional aja (login session, preference). Kamu bisa hapus dari setting browser kapan aja — gak akan nge-break aplikasi, cuma kamu perlu login lagi.

7. Perubahan kebijakan

Kalau kami update kebijakan ini, perubahan material kami umumin via email 14 hari sebelum berlaku. Pakai layanan setelah update = setuju sama versi baru.

8. Pertanyaan

Tanya privasi atau request penghapusan data: kidnovell.richie@gmail.com atau via halaman kontak.
