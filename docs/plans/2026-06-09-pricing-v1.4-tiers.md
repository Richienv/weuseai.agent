# Pricing v1.4 — 6-tier restructure + FOMO launch mechanic — Implementation Plan

> **For Claude:** Execute task-by-task with TDD (superpowers:test-driven-development). Ship in 2 PRs.

**Goal:** Add two cheaper entry tiers (`bare` Rp 99k, `solo` Rp 399k), reduce `voice-starter` 699→599k and `library-full` 899→799k (with a 999k psychological strikethrough anchor), keep `done-for-you` at 1.299k; then a launch FOMO mechanic on the landing (honest framing — no fake discount expiry).

**Architecture:** `supabase/functions/_shared/tier-personas.ts` stays the single source of truth; three hand-maintained mirrors (`api/_shared/tier-catalog.ts`, `admin/assets/admin-shared.js`, `index.html`) + drift gates keep it honest. The provisioning service is extended to accept the two new slugs natively. Old slugs (`starter/pro/studio`) keep resolving via the existing alias map (untouched).

## Locked decisions (architectural forks the consult delegated)

1. **`bare` is persona-free** (`personas: []`). Invariant #1 ("the-pro at index 0 of every non-null list") is relaxed to "every non-null **non-empty** list." `bare` = vanilla Hermes, DeepSeek chat in Bahasa, no SOUL.md persona, no voice.
2. **`bare` emits ZERO agent slugs.** Fix `customer-flow` default-hoisting so an empty tier persona list does not force `the-pro`. `bundle-pull-script` already exits 0 cleanly on an empty CSV → no bundle fetch, no 403.
3. **Provisioning accepts `bare`/`solo` natively.** Add both to the provisioning service `Tier` union, `VALID_TIERS`, `TIER_SPEC` (→ smallest `{2,4096,50}`), `TIER_LLM_LIMIT_CENTS` (→ 300 = $3). `solo` grants 3 personas + voice OFF.
4. **Reject consult §H lossy alias.** `bare→starter / solo→starter / voice-starter→starter` collapses three distinct tiers (0-persona / 3-no-voice / 3-voice) into one provisioning behavior and would MIS-PROVISION `bare`/`solo` buyers. Checkout is deferred, so we do NOT add that alias. Admin-form provisioning emits the real new slug; the provisioning service handles it natively.
5. **`persona_library` derived** from `personas.length > 0` (DRY — no redundant feature flag). **`setup_fee_anchor_idr: 999_000`** added as optional display metadata on `library-full` only; never charged (the charged amount is `setup_fee_idr: 799_000`).
6. **`index.html` is NOT drift-tested** → PR1 can change the catalog + tested mirrors without touching the landing; the landing redesign + strikethrough + FOMO all live in PR2.
